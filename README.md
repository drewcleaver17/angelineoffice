# Angeline Office Landing Page

Quiet-luxury, high-trust, mobile-first static website for **Angeline Office** (angelineoffice.com).

## Project overview
This is a GitHub Pages-ready one-page site for a founder-led B2B sales and marketing representation agency focused on Austin hemp vendors and wholesale channel growth.

### Core positioning
- White-collar sales infrastructure for Austin hemp brands.
- We build accounts. Vendors fulfill the product.
- Field sales without inventory handling.

## Local editing instructions
1. Clone the repo.
2. Open `index.html`, `styles.css`, and `script.js` in your editor.
3. Preview by opening `index.html` directly in your browser.

## File structure
- `index.html` — semantic page structure and all landing page copy
- `styles.css` — responsive design system and component styling
- `script.js` — mobile nav toggle + dynamic footer year
- `CNAME` — custom domain setting for GitHub Pages
- `assets/` — placeholder folder for brand assets and OG image

## Deployment instructions (GitHub Pages)
1. Push repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` branch and `/ (root)` folder.
5. Save.
6. Confirm site publishes at `https://YOUR_GITHUB_USERNAME.github.io/angelineoffice.com/` (or your custom domain).

## Brand notes
- Visual style: whisper-luxury, restrained, operationally disciplined.
- Audience priority: Austin hemp / THCa vendors seeking B2B wholesale growth.
- Avoid cannabis clichés and product-handling implications.

## Compliance disclaimer
Angeline Office provides sales and marketing representation services. Angeline Office does not manufacture, warehouse, transport, deliver, or take possession of hemp, THCa, cannabis, regulated products, or client inventory. Product compliance, supply, delivery, and fulfillment remain the responsibility of the vendor.
